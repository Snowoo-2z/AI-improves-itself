Comment ça marche

1. Je réponds via ce chat.
2. Je réfléchis sur ma propre réponse.

AI-improves-itself — recherche & expérimentation. Les auto-modifications de l'IA sont auditées sur la page Prompt système. Aucune clé API n'est stockée dans le prompt ni dans le repo.
