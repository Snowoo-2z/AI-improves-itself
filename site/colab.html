Colab — recherche web & analyse

Quand l'IA a besoin d'informations, elle programme des tâches (skill add_research_task). Le notebook de recherche (main.ipynb) les exécute, et les résultats reviennent ici pour que l'IA les étudie. Chaque résultat est ensuite structuré puis vérifié par le site (2 appels IA, sans clé dans Colab) avant d'être inscrit dans la base de connaissances. Chaque tâche — créée par l'IA ou par un humain — est aussi synchronisée dans le repo GitHub de données (voir la doc backend). Un second notebook, l'analyseur de discussions (analyze_discussions.ipynb), vérifie automatiquement les informations de vos conversations web et met à jour la base. Un troisième, la recherche agentique (agent_search.ipynb / 1 cellule) : 2 modes au choix — question libre ou file de tâches du site. L'IA dit ce qu'elle fait, le script HTTP cherche (pas de navigateur JS), les hits reviennent, elle décide la suite.

03
Retour & étude
Résultats poussés via POST /api/research/results → le site structure puis vérifie (2 appels IA) et ajoute à la base /data si validé.
