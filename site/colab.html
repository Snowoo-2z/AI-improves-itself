Colab — recherche web

Quand l'IA a besoin d'informations, elle programme des tâches (skill add_research_task). Le notebook Colab (script mis à jour par l'IA via ces tâches — « j'ai besoin de vérifier X » → nouvelle tâche dans colab/tasks.json) les exécute, et les résultats reviennent ici pour que l'IA les étudie. Chaque résultat est ensuite structuré puis vérifié par le site (2 appels IA, sans clé dans Colab) avant d'être inscrit dans la base de connaissances. Chaque tâche — créée par l'IA ou par un humain — est aussi synchronisée dans le repo GitHub de données (voir la doc backend).
